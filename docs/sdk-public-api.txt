# Supported SDK consumer API

This inventory is the supported Agent/Caller and C ABI surface. Odin cannot hide procedures inside a package; helpers not listed here are unsupported internals. Removing a listed name, changing a listed C signature, or adding a `THIRP_API` symbol without updating this file and CHANGELOG.md is a compatibility change.

[package agent]
types: Agent AgentConfig LocalTarget EphemeralConfig Hosting AgentError
procs: agent_init agent_run agent_stop agent_destroy agent_is_connected register_service unregister_service host_ephemeral hosting_destroy

[package caller]
types: Caller CallerConfig Conn CallerError ConnError
procs: caller_init caller_destroy dial dial_join_code conn_read conn_write conn_half_close conn_close conn_destroy
